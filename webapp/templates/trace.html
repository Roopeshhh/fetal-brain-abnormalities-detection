Why Convert Grayscale to 3-Channel RGB?

B-mode medical ultrasound inherently encodes scalar acoustic reflectivity ($R=G=B$). The scan is expanded into a 3-channel RGB representation ($C=3$) because the Swin-Tiny Transformer backbone was pre-trained on ImageNet-1k, which strictly mandates a 3-channel input tensor in its linear patch embedding projection layer.

Architectural Formulation Note

The deployed Swin-Tiny model is a 15-class multi-class classifier trained using categorical loss. The binary decision ("Normal vs Any Abnormality") is mathematically derived from the probability assigned to the Normal class vs the cumulative probability mass $\sum_{k \neq \text{normal}} P_k$ across all 14 abnormality categories.
